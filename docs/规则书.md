# 策略示例与配置边界

本仓库保留可供研究的网格/趋势策略示例，不表示任何人的当前持仓、账户余额或交易计划。

- API凭据仅通过操作者自己的环境变量配置，不应提交到Git。
- `GRID_AVOID_SYMBOLS` 是可选的逗号分隔排除列表，默认空；不携带原作者的持仓列表。
- SKR示例需要操作者明确提供 `SKR_ANCHOR`、`SKR_STEP`、`SKR_INVEST`、`SKR_RATIO_MIN`、`SKR_RATIO_MAX`，没有私人交易区间默认值。
- 其他公开代码中的策略参数是示例代码，不构成投资建议或收益承诺，使用者必须自行理解、配置与验证。
- 驾驶舱默认只读；独立 `bots/` 和 `debug/` 内部分脚本会执行真实交易，`deploy/` 会停止或启动远端进程，不得误当只读诊断。
- 先前公开版本曾带有个人交易语境；清理当前分支不等于已删除历史版本或第三方副本。
