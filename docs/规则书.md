# 网格滚仓机器人规则书 v1（主人钦定 2026-08-30）

> 机器人：`scripts/grid_roll.py`（跑 VPS）｜ 接口：Bybit /v5/fgridbot/*（合约网格）
> 主人原文：用机器人找交易活跃的币开网格，分析做多/做空/中性；每赚 30% 关闭机器人，拿赚的钱开下一个；每局 10U 本金，不怕爆仓；沿用 100 存 50 阶梯。

## 一、参数冻结表（v1）

| 参数 | 值 | 说明 |
|---|---|---|
| 每局本金 | 10 U | 主人钦定，爆仓=亏光 10U，不追加不扛 |
| 杠杆 | 10x | 与主人现有 MOVR 网格一致 |
| 网格类型 | 算术（grid_type=1，官方：1=算术等差价/2=等比等比例） | 上移/下移官方标注仅算术格适用；等比格 App 能存参数但功能无效 |
| 格数 | 35 | 区间内格子密度 |
| 区间 | 现价 ±2×ATR(4h,14) | 上下边界，截断到 tick |

| 止损 | −45%（stop_loss_per=0.45） | 保命兜底（主人"不怕爆仓"但滚仓要本金，45% 止损留 55% 继续滚） |

| 阶梯 | 滚仓权益 ≥100U → 划 50U 到主账户；≥500 → 划 250U；≥1000 → 全停报告 | 沿用主人钦定阶梯 |

## 二、与项目研究的关系（诚实声明）

- 45+ 批回测结论：**静态网格扣费后期望全负**（S24/S28），网格赚震荡钱、趋势还回去；本机器人不改变该数学。
- 主人现有 MOVR 网格 +53%/2 天是单样本运气区，不可外推年化。
- 本机器人的本质 = 主人钦定的**滚仓实验**（与滚仓机器人同族：小注、多局、阶梯划转、不怕爆仓），参数冻结 + 平台止盈止损硬约束，不冒充 alpha。
- 网格正期望唯一来源 = 币价在区间内震荡的概率；分类（多/空/中性）用的是已证伪无方向预测力的 EMA 方向，仅作区间偏向，不是信号。

## 三、启动对账铁律（沿用 v3.3）

- 启动时若注册表有"运行中"网格而进程已死 → FATAL，不自动关仓，交总管人工处理。
- 关闭网格（close 接口）后必须核对 detail.status=COMPLETED 再开下一局。

## 四、账本

`grid_registry.json`：每局 {bot_id, sym, mode, 本金, open_at, close_at, pnl, pnl_per, result}；滚仓权益=本金池+累计已实现盈亏；阶梯划转与终止事件写日志 `logs/grid_roll.log`。

## 五、v1.1 修订（2026-08-31，随主人"开新机器人/赚30%滚下一个"指令）

- **资金账户**：网格开仓从 Bybit **FUND 资金账户**扣款（非 UTA 统一账户）——此前"not enough money"根因；主人已在 App 把 AI 子账户资金划入 FUND。
- **多网格监控**：`grid_bot_id.txt` 每行一个 bot_id，循环巡逻所有网格；任一网格达标(+30%)/触止损(-45%) 或平台已平 → 记账进 history 并从列表移除。
- **自动开仓**：巡逻列表为空时自动 `fgridbot/create` 开新局（FUND 扣款，10U/10x，tp_sl_type=1 平台硬止盈止损）；开仓失败(非资金不足)的币进 skip 列表（只保留最近 20 个）。
- **参数微调**：20 日振幅门槛 8%~25% → 6%~55%（2026-08-30 高波动行情实测 92% 币超 25%）；格数按 `minOrderAmt` 自适应（10~35）；价格全部 tick 对齐（否则 `validatePrecision fail`）。
- **单仓上限修订**：滚仓制 + 已存在网格不重复开（当前 DOGE 为主人 App 所开、TRX 为 API 所开，共 2 格在跑）。
- **部署**：VPS `/opt/quant/`，`.env_grid` 存 AI 子账户 API key；本地驾驶舱 `gridlogs/` 同步快照。

## 六、v1.2 修订（2026-08-30 夜，主人钦定「持续找刚过/接近历史高低点的币试水」）

- **方向网格选币（新增优先级）**：按成交额 Top80 扫描，用月线(排除当月)算历史最高/最低，距极值 2% 内视为"接近"：
  1. 刚破 ATH → **做空网格**（fade 超涨）
  2. 刚破 ATL → **做多网格**（接飞刀博反弹）
  3. 接近 ATH → 做空网格
  4. 接近 ATL → 做多网格
  5. 都没有 → 退回常规 EMA 分类中性/方向网格
- **并行上限**：`MAX_GRIDS=10`（2026-08-31 主人钦定"再开 7 个，有合适的就开"；10U/格，最大敞口 100U）；FUND 余额 < 15U 暂停开新局留弹药。
- **不重复押注**：跳过已在跑的币；`AVOID_SKIP={'MOVRUSDT'}`——主人手动子账户已有 MOVR 网格，AI 账户不跟仓。
- **开仓失败**：非资金原因失败进 skip 列表（保留最近 20 个）；资金不足停 10 分钟重试。
- **方向网格不传 entry_price**（2026-08-30 深夜踩坑）：限价入场单不成交会让网格停在 `AWAIT_ACTIVATION` 挂起且方向被平台改中性；现改为市价立即入场。状态判断用白名单式——只有 CLOSE/SETTLED/COMPLETE/LIQUIDAT/FAIL/STOP 才算完局。
- **grid_mode 映射纠正（2026-08-30 深夜）**：此前误记 1=做多/2=中性/3=做空，官方文档为 **1=中性、2=做多、3=做空**；已全量纠正（EMA 分类与 ATH/ATL 方向网格）。TP/SL 单位确认无误：0.30=+30%、0.45=-45%（文档：0.1 means 10%）。
- **平台 SL 观察（已结案，2026-08-31 凌晨）**：API 传 `stop_loss_per=0.45` 实测被平台当作 ~0.45% 级提前止损（TRX/APT 连续在 -0.2%~-1.0% 被 `CANCELED_AUTO_SL` 平掉），与 -45% 口径冲突且引发同币 churn。**决定：不再传平台 TP/SL 参数，+30%/-45% 由软件巡逻按 pnl_per 强制执行**（5 分钟粒度）；强平价仍是最后的灾难兜底。
- **输局冷却**：某币网格以亏损结束 → 该币冷却 4 小时不重开（防平台止损后立刻重开同币烧钱）；盈利结束不冷却。
- **上移/下移全开（2026-08-31 深夜，主人钦定"以后所有机器人都要开"）**：新网格一律 `grid_type=1` 算术格 + 移动终止价经验证接口钳位（经验：移动终止价过极端如 max×1000 会触发平台 `TRIGGER_FBU_FAIL`/`FAILED_INITIATION`，温和值可用）。已存在的等比格机器人由主人在 App 开启。风险已知：做空格上移=逆势加空、做多格下移=逆势加多（主人原话"这个雷我清楚"），靠 -45% 软件止损与强平价兜底。

## 七、SKR 克隆塔（2026-08-31 主人钦定）

- **主人 SKR 机器人**：App 手开，`bot_id YOUR_BOT_ID`，做空/20x/100格/等比/移动(1, 0.000001)/10U。**永不关闭**——主机器人对 noclose 列表只巡逻记录、不执行 +30%/-45%（驾驶舱 🔒 标识）。
- **克隆规则**：锚点=历史最高价 0.026222；**记录高每再涨 0.003 → 自动克隆一单**（参数完全复制主人的，区间按当前价等比缩放 min×0.9738 / max×1.0995）；克隆同样进 noclose 长期观察。
- **资金红线**：克隆时 FUND < 12U → 停止克隆并写 `skr_fund_low.txt` 告警（总管负责通知主人补资金）；FUND ≥ 12U 自动恢复。
- **隔离知识**：SKR 上平台拒过的组合——20x+无移动、20x+移动(12.5/0.05)、10x+移动(12.5) 全部 `FAILED_INITIATION`/`TRIGGER_FBU_FAIL`（资金自动退回）；仅 10x+无移动 与 App 手开的 20x+移动(1/0.000001)+等比 能活。
- **监控**：`skr_clone.py` 跑 VPS（60 秒行情轮询），状态/克隆日志同步到驾驶舱（SKR 克隆塔条：记录高/下次触发线/已克隆数/资金状态）。
- **API 全局限速 0.45s/请求**，防止公开端点 10006；月线极值进程内缓存。
- **诚实声明**：方向网格 = 极值反转赌注（fade extremes），S24-S46 研究已证反转族无统计优势；本模式仍是主人钦定的 10U 试水实验，平台硬止盈止损封顶风险，不做胜率承诺。
